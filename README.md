# 考研加油站 - 学习伴侣网页

一个为考研学生设计的学习管理网页，包含番茄钟、目标设定、学习记录、成就系统等功能。

## 功能特性

- **番茄钟** - 支持 25/5、45/10、50/10、15/3 多种模式，自动切换工作/休息
- **目标设定** - 每日/每周/每月目标，可视化进度条追踪
- **学习记录** - 按日期分组展示，支持手动添加和自动记录
- **成就系统** - 13 种成就徽章，激励持续学习
- **连续打卡** - 周视图打卡日历，保持学习习惯
- **等级系统** - 10 个等级，从"考研萌新"到"知识之神"
- **励志语录** - 随机切换的考研励志语录
- **五彩纸屑** - 完成任务时的庆祝动画
- **快捷键** - 空格键快速开始/暂停番茄钟
- **本地存储** - 数据保存在浏览器中，无需服务器

##  使用技巧

- 按**空格键**随时开始/暂停番茄钟
- 完成番茄钟后会自动记录学习时间
- 可以手动添加学习记录，选择不同科目
- 目标进度可以手动点击 +/- 按钮调整
- 所有数据保存在浏览器本地，更换浏览器/设备数据会丢失
