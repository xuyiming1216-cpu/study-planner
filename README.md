# 📚 考研加油站 - 学习伴侣网页

一个专为考研学生设计的学习管理网页，包含番茄钟、目标设定、学习记录、成就系统等功能。

## ✨ 功能特性

- 🍅 **番茄钟** - 支持 25/5、45/10、50/10、15/3 多种模式，自动切换工作/休息
- 🎯 **目标设定** - 每日/每周/每月目标，可视化进度条追踪
- 📝 **学习记录** - 按日期分组展示，支持手动添加和自动记录
- 🏆 **成就系统** - 13 种成就徽章，激励持续学习
- 🔥 **连续打卡** - 周视图打卡日历，保持学习习惯
- 🎮 **等级系统** - 10 个等级，从"考研萌新"到"知识之神"
- 💬 **励志语录** - 随机切换的考研励志语录
- 🎉 **五彩纸屑** - 完成任务时的庆祝动画
- ⌨️ **快捷键** - 空格键快速开始/暂停番茄钟
- 💾 **本地存储** - 数据保存在浏览器中，无需服务器

## 🚀 部署到 GitHub Pages

### 方法一：直接上传（最简单）

1. 在 GitHub 上创建一个新仓库，例如 `study-planner`
2. 将 `index.html` 文件上传到仓库根目录
3. 进入仓库 Settings → Pages
4. Source 选择 `main` 分支，点击 Save
5. 等待几分钟，网页即可通过 `https://你的用户名.github.io/study-planner/` 访问

### 方法二：命令行上传

```bash
cd /Users/xudan/Desktop/plan
git init
git add index.html README.md
git commit -m "📚 初始化考研加油站"
git branch -M main
git remote add origin https://github.com/你的用户名/study-planner.git
git push -u origin main
```

然后在 GitHub 仓库 Settings → Pages 中启用 GitHub Pages。

## 💡 使用技巧

- 按**空格键**随时开始/暂停番茄钟
- 完成番茄钟后会自动记录学习时间
- 可以手动添加学习记录，选择不同科目
- 目标进度可以手动点击 +/- 按钮调整
- 所有数据保存在浏览器本地，更换浏览器/设备数据会丢失
